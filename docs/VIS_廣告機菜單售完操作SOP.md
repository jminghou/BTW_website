# VIS 電視菜單「售完」操作 SOP

> 適用對象：現場販售人員  
> 操作範圍：只用手機在播放畫面操作，**不進入後台**  
> 最後更新：2026-08-21

---

## 一、這個功能在做什麼？

當某一道餐點賣完時，現場人員可用手機把該品項標成「售完」。手機與現場畫面是同步的，手機標示完成後，現場畫面會一起變成售完：

- 右邊列表：該項文字變灰，編號改成「售完」
- 左邊大圖：不再輪播到已售完的品項
- 其他餐點的編號**不會改號**（例如 3 售完，4 仍是 4）

賣完標售完、後來又有貨時，用同樣方式再點兩下即可恢復。

---

## 二、開始前請先確認

1. **進入網站請掃描本據點的 QR Code。** QR Code 由該據點營運提供（見附件），不要自己上網搜尋網址。
2. **QR Code 與網址不得外傳**（包含 LINE、社群、私人轉寄、拍照上傳）。僅限本據點當班人員使用。
3. **不要登入後台、不要改設定。** 本 SOP 全部在播放畫面完成。
4. 確認畫面已是當日、當餐期的菜單（例如午餐／晚餐），且右邊看得到餐點列表。

> ⚠ 若畫面是黑底「待機中」或完全不是菜單，請立刻聯絡該據點營運，不要自行嘗試進入後台。

## 三、如何進入網站（一律掃 QR Code）

1. 打開手機相機（或營運指定的掃碼方式）。
2. 掃描**本據點附件中的 QR Code**。
3. 點選跳出的連結，用手機瀏覽器開啟菜單畫面。
4. 確認已看到三欄式菜單（左邊大圖、右邊列表）後，再進行售完操作。

> ⚠ 只掃描本據點營運提供的 QR Code。不要掃描來路不明、其他據點，或他人傳來的 QR Code。

---

## 四、日常操作步驟

請用手機點**右邊餐點列表**，不要點左邊大圖。

### 標示售完

1. 找到右邊列表中已賣完的那一道。
2. 用手指對該列**連點兩下**（兩下之間不要停超過約 1 秒）。
3. 第一次點可能會看到該列稍微變亮，這是正常提示，請立刻再點第二次。
4. 成功後：
   - 中文、英文、價格變灰
   - 前面圓圈改為「售完」
   - 左邊大圖不再播這道菜
   - 現場廣告機約 2 秒內會同步變成售完

### 取消售完（又有貨了）

1. 對準已經是灰色、「售完」的那一列。
2. 再連點兩下。
3. 文字顏色與編號應恢復原狀，左邊大圖會重新輪播到這道菜；現場廣告機約 2 秒內會一併恢復。

### 同一餐期會記住

- 同一餐（例如今天午餐）標過的售完，畫面短暫閃一下或重載後，通常仍會保持售完。
- 換餐期後（午餐結束改播晚餐、或隔天），會自動全部恢復成原始菜單，不必手動清除。

## 五、操作時請注意

| 請這樣做 | 請不要這樣做 |
|---|---|
| 掃描本據點營運提供的 QR Code 進站 | 自己打網址、掃描不明或其他據點的 QR Code |
| 點**右邊列表**的餐點列 | 點左邊大圖、日期、Logo |
| 連點兩下、兩下要夠快 | 只點一下，或兩下間隔太久 |
| 點餐點名稱那一列 | 點餐廳標題（例如「小不點海苔飯捲」那顆標籤） |
| QR Code 只給當班人員使用 | 把 QR Code 或網址傳給外人或其他據點 |

其他說明：

- 售完後，其他品項號碼維持原號，不用擔心會跳號。
- 可同時標示多道售完。
- 若全部都標成售完，左邊大圖會停在最後一張，這是正常現象。

## 六、狀況排除

多數問題出在「沒掃對 QR Code」或「點錯地方」。請先確認已用本據點 QR Code 打開菜單，再對右邊餐點列連點兩下。

| 狀況 | 可能原因 | 現場可做的處理 |
|---|---|---|
| 掃不到／打不開頁面 | 沒對準、光線不足，或不是本據點的 QR Code | 重新對準附件中的 QR Code 再掃一次；仍不行請聯絡營運 |
| 點一下沒反應 | 需要連點兩下 | 對同一列再連點兩下，兩下不要停太久 |
| 連點兩下仍沒變 | 點到左邊大圖、餐廳標題，或兩下間隔太久 | 改點右邊餐點列，再試一次 |
| 手機已售完，廣告機約 2 秒後還沒變 | 廣告機還在載入、或網路較慢 | 再等幾秒；仍沒變請聯絡營運，請他們重開廣告機播放頁 |
| 標成售完後，想改回來 | 又進貨／標錯 | 對灰色那一列再連點兩下 |
| 換餐後還看得到上一餐的售完 | 還在顯示上一餐菜單 | 確認畫面左側時段已換成這一餐（午餐／晚餐等）；若沒換，聯絡營運 |
| 畫面變成黑底「待機中」 | 目前沒有可播放的菜單 | 聯絡該據點營運，不要自行改設定 |
| 畫面不是三欄菜單（沒有右邊列表） | 播到其他版型或非菜單畫面 | 本功能僅適用三欄每日菜單；聯絡營運確認播放內容 |
| 不小心把 QR Code 或網址傳出去 | 資安風險 | 立刻通知該據點營運，由營運後續處理 |

現場人員**不要**嘗試：

- 登入後台
- 自行輸入或修改網址
- 掃描非本據點、來路不明的 QR Code
- 把 QR Code 或網址存到公開資料夾或群組

## 七、什麼時候要請營運協助？

以下情況請找**該據點營運**，不要自己進後台：

1. 掃 QR Code 後不是菜單畫面，或顯示「待機中」
2. 已用手機對右邊列表連點兩下，仍完全沒反應
3. 播放的不是今天、這一餐的菜單
4. QR Code 遺失、毀損、外流，或無法開啟

聯絡時可簡短說明：

- 據點／廠區
- 目前畫面狀況（例如：有菜單但點兩下沒變售完／待機中）
- 是否已掃描本據點附件中的 QR Code
